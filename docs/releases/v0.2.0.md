# edownloader 0.2.0 — in your language

**edownloader now speaks eight languages.** English, Français, Deutsch, Español, Italiano, Português, 日本語 and 简体中文: the interface, from its buttons to the common error messages that tell you what to do when YouTube asks for a sign-in.

## Highlights

- 🌍 **Eight languages.** Every label, hint and regular notification is translated, along with the download errors edownloader recognises and explains. By default edownloader follows your Windows display language (the first of your preferred languages it has a translation for), and falls back to English otherwise.
- 🔀 **Switch at any time.** Settings › appearance › Language. The change applies at once, with no restart.
- ⚡ **Faster HLS and DASH streams.** Streams served in fragments (most video sites, `.m3u8` and `.mpd` links) now download up to 8 fragments at once, following the *Connections per file* setting; a 10-minute test stream comes down twice as fast.
- 🧭 **Clearer dead ends.** A `blob:` link, a copied `.m3u8`/`.mpd` playlist the server refuses, or a DRM-protected video now each get a plain explanation and what to do instead (usually: paste the page's address).
- 📐 **Settings that fit.** Labels and hints wrap instead of running past the window, so longer languages (and a narrower window) keep every button in reach.
- 🪟 **Maximize goes both ways.** The maximize button now restores the window to its previous size on the second click; before, it stayed maximized.

Also included: the download folder path in the command bar is shortened when space runs out · clearer wording for the MP4 setting and for the tool checksums, which are verified where their projects publish one.

## Update

Already on 0.1.0? edownloader downloads this version in the background and installs it when you close the app, or right away with **Restart to update** in the banner.

New here? Download **`edownloader_0.2.0_x64-setup.exe`** below and run it. edownloader installs for your user only, with no administrator rights required. On first launch, click **Install** in the yellow banner to fetch the tools (about 270 MB, mostly ffmpeg).

> [!NOTE]
> The installer and `edownloader.exe` are signed with a self-signed certificate. Windows does not recognise it as a trusted publisher yet, so SmartScreen may show *"Windows protected your PC"* on first launch. Click **More info → Run anyway**.

`SHA256SUMS.txt` contains the installer checksum. `latest.json` is what the updater reads: the installer's address and its signature.

## Translations

The translations are new: if a word reads oddly in your language, [open an issue](https://github.com/InstaZDLL/edownloader/issues) with the text you see and what you would expect. Each language lives in one file, `locales/<code>.json`.

Portuguese is written in Brazilian Portuguese, avoiding regional turns of phrase; a Windows display language of Portuguese (Portugal) uses it too. Any Chinese display language, Traditional included, gets Simplified Chinese.

## Known limitations

- Windows only.
- Rare technical messages stay in English: a yt-dlp error edownloader does not recognise (shown as yt-dlp wrote it), a lost connection to aria2, and some tool-installation and update errors.
- Some Chromium-based browsers lock their cookie store with app-bound encryption that no tool can read. edownloader says so; export `cookies.txt` with a browser extension and paste it instead.
- The download queue is not saved when you close the app.
